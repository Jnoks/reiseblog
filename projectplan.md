## 5. Ablauf im Alltag

- **Daily** (max. 10 Min., nach dem Live Call): Was gestern? Was heute? Wo hänge ich?
- **Board-Flow:** To Do → In Progress (max. 1 Karte pro Person) → Review → Done
- **Git:** Feature-Branches, atomare Commits mit Typ-Prefix, Pull Request + Review durch andere Person, main bleibt lauffähig
- Aufgaben max. 1–2 Tage groß – was länger hängt, wird unterteilt

## 6. Definition of Done (gilt für jede Aufgabe)

- [ ] Entspricht dem Figma-Design
- [ ] Responsive geprüft (320 / 768 / 1280)
- [ ] Alt-Texte vorhanden, semantisches HTML
- [ ] Review bestanden und auf main gemergt

## 7. Risiken & Gegenmaßnahmen

| Risiko | Gegenmaßnahme |
|---|---|
| Merge-Konflikte | Bereichsaufteilung, täglich pullen, klein committen |
| Aufgabe zieht sich | Im Daily ansprechen, Aufgabe unterteilen und neu zuteilen |
| Teammitglied fällt aus | Board zeigt jederzeit den Stand; Bereiche sind dokumentiert, Übernahme möglich |
| Design-Unklarheiten | Sofort im Team klären statt raten; Entscheidung als Kommentar an die Karte |
